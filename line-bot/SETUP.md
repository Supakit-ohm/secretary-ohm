## 1. สร้างโปรเจกต์ Apps Script

1. เปิด https://script.new → ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) ว่า **Jack LINE bot**
2. ไอคอนเฟือง ⚙️ **Project Settings** (แถบซ้าย)
   - ติ๊ก ✅ **Show "appsscript.json" manifest file in editor**
3. กลับไปหน้า **Editor** (ไอคอน `< >`)

## 2. วางโค้ด 4 ไฟล์

เปิดแต่ละไฟล์ในโฟลเดอร์นี้ด้วย Notepad → Ctrl+A → Ctrl+C แล้ววางทับ/สร้างใน editor:

| ใน editor | วางจากไฟล์ |
|---|---|
| `appsscript.json` (มีอยู่แล้ว — ลบของเดิมทั้งหมดก่อนวาง) | `appsscript.json` |
| `Code.gs` (มีอยู่แล้ว) → กด ⋮ → **Rename** เป็น `Bot` แล้ววางทับ | `Bot.gs` |
| ปุ่ม **+** → Script → ชื่อ `Config` | `Config.gs` |
| ปุ่ม **+** → Script → ชื่อ `Persona` | `Persona.gs` |
| ปุ่ม **+** → Script → ชื่อ `Files` (ขั้นที่ 8) | `Files.gs` |

กด 💾 Save (Ctrl+S)

## 3. ใส่ค่าลับ (Script Properties)

⚙️ **Project Settings** → เลื่อนลงล่างสุด **Script Properties** → **Add script property** ทีละตัว (คัดลอกค่าจาก `secrets.local.txt`):

| Property | ค่า |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | ค่าในบรรทัด LINE_CHANNEL_ACCESS_TOKEN |
| `LINE_CHANNEL_SECRET` | ค่าในบรรทัด LINE_CHANNEL_SECRET (ยังไม่ได้ใช้ เก็บไว้ก่อน) |
| `OPENAI_API_KEY` | ค่าในบรรทัด OPENAI_API_KEY (ขึ้นต้น `sk-`) |

กด **Save script properties**

## 4. รัน `setup` (ให้สิทธิ์ + เช็กทุกอย่าง)

1. หน้า Editor → เปิดไฟล์ `Bot.gs` → ช่องเลือกฟังก์ชันด้านบน เลือก **setup** → กด ▶ **Run**
2. จะมีหน้าขอสิทธิ์ → **Review permissions** → เลือกบัญชี supakit6906
   → ขึ้น "Google hasn't verified this app" → กด **Advanced** → **Go to Jack LINE bot (unsafe)** → **Allow**
   (ปกติสำหรับสคริปต์ที่เราเขียนเอง — สิทธิ์ที่ขอคือ "เรียก URL ภายนอก" กับ "Cloud Datastore/Firestore")
3. ดู **Execution log** ด้านล่าง ต้องได้ ✅ ครบ 3 บรรทัด + 🎉:
   ```
   ✅ Firestore: uid ... · งานในระบบ N รายการ
   ✅ LINE: บอตชื่อ "Jack" (@...)
   ✅ OpenAI (gpt-6-luna...): "พร้อม"
   🎉 พร้อมทุกอย่าง
   ```
   ถ้ามี ❌ ดูหัวข้อ **แก้ปัญหา** ท้ายไฟล์ · แก้แล้วรัน `checkAll` ซ้ำได้เรื่อยๆ (ไม่ต้องรัน setup ใหม่)

## 5. Deploy เป็น Web app

1. ปุ่มสีน้ำเงิน **Deploy** (ขวาบน) → **New deployment**
2. เฟือง ⚙️ ข้าง "Select type" → **Web app**
3. ตั้งค่า:
   - Description: `Jack v1`
   - Execute as: **Me (supakit6906@gmail.com)**
   - Who has access: **Anyone**  ← ต้องเป็น Anyone ไม่งั้น LINE ส่งเข้ามาไม่ได้ (กันคนอื่นด้วยรหัสลับใน URL + ล็อก LINE ของโอม)
4. **Deploy** → คัดลอก **Web app URL** (ลงท้าย `/exec`)

## 6. ต่อ LINE เข้ากับ Jack

1. ⚙️ Project Settings → Script Properties → เพิ่ม `WEBAPP_URL` = URL ที่คัดลอกมา → Save
2. Editor → เลือกฟังก์ชัน **showWebhookUrl** → ▶ Run → ต้องขึ้น `✅ ตั้ง Webhook URL ใน LINE ให้แล้ว`
   (โค้ดตั้งให้ผ่าน LINE API เลย ไม่ต้องไปวางเองใน LINE Developers)
3. เช็กใน [LINE Developers Console](https://developers.line.biz/console/) → channel ของ Jack → แท็บ **Messaging API**:
   - **Use webhook** = เปิด
   - **Webhook redelivery** = ปิด
   - ⚠️ ถ้ากดปุ่ม **Verify** แล้วขึ้น error `302 Found` — **ไม่ต้องสนใจ** เป็นเรื่องปกติของ Apps Script (ข้อความจริงยังเข้าบอตได้)

## 7. ทดลองใน LINE

1. เปิดแชท Jack → พิมพ์ **สวัสดี** → Jack ตอบว่าจำ LINE ของโอมไว้แล้ว (ข้อความแรกใช้ผูกบัญชีเท่านั้น)
2. ลองต่อ:
   - `เดือนนี้ใช้ไปเท่าไหร่` → Jack เล่าตัวเลขที่ระบบคำนวณ + บอก **"ข้อมูลถึงวันที่ …"** (ตั้งแต่ขั้นที่ 1 ข้อ 56: Jack **ไม่จด/แก้/ลบรายรับ-รายจ่าย** แล้ว — โอม import CSV KBank ในแอปเดือนละครั้ง)
   - `เพิ่มงาน โทรหาซัพพลายเออร์ พรุ่งนี้`
   - `วันนี้มีงานอะไรบ้าง`
   - `journal วันนี้ขายดี ลูกค้าประจำมาเยอะ`
   - `เดือนนี้ใช้ไปเท่าไหร่ หมวดไหนเกินงบ`
   - `ช่วยวิเคราะห์การใช้เงินเดือนนี้หน่อย` → ใช้รุ่นกลาง (แพงกว่า ~20 เท่า)
3. เปิดแอปเลขา (คอม/iPhone) → รายการที่จดต้องขึ้นเองภายในไม่กี่วินาที (ประวัติการกระทำมีคำว่า "(LINE)")

**คำสั่งพิเศษ** (ไม่เสียค่า AI): `สถานะ jack` = ดูค่า AI เดือนนี้/error ล่าสุด · `ลืมบทสนทนา` = ล้างความจำแชท

## ขั้นที่ 8 (ข้อ 56) — Garmin → Apple Health → iOS Shortcuts → Jack (เพิ่ม 2026-09-30)

ภาพรวม: นาฬิกา Garmin → แอป Garmin Connect → Apple Health (ในไอโฟน) → Shortcut "Jack สุขภาพ" อ่านจาก Health แล้วส่งให้ Jack → ลงหน้า Health ในแอป + ได้ XP เอง
ทำไมต้องผ่าน Shortcut: Garmin ไม่มี API ให้บุคคลทั่วไป · ไอโฟนล็อกข้อมูล Health ตอนล็อกจอ เลยให้ Shortcut ทำงาน **ตอนเปิด LINE ครั้งแรกของวัน** (มือถือปลดล็อกอยู่แน่นอน)

### ส่วน A — Garmin Connect ส่งข้อมูลเข้า Apple Health (ทำครั้งเดียว)
1. เปิดแอป **Garmin Connect** → เมนู ☰ (หรือ "เพิ่มเติม/More") → **การตั้งค่า (Settings)** → **แอปที่เชื่อมต่อ (Connected Apps)** → **Apple Health** (เมนูอาจย้ายตามเวอร์ชัน ถ้าไม่เจอให้ค้นคำว่า Apple Health ในหน้าการตั้งค่า)
2. เปิดทุกหมวด โดยเฉพาะ **การนอน (Sleep) · ก้าว (Steps) · กิจกรรม/ออกกำลังกาย (Activities/Workouts) · อัตราการเต้นหัวใจ (Heart Rate)** → ถ้าเด้งหน้า Health ขอสิทธิ์ ให้กด **เปิดทั้งหมด (Turn On All) → อนุญาต**
3. ตรวจสิทธิ์อีกฝั่ง: แอป **สุขภาพ (Health)** → รูปโปรไฟล์มุมขวาบน → **แอป (Apps)** → **Garmin Connect** → ให้เปิดทุกข้อ
4. **การตั้งค่าไอโฟน → ทั่วไป → รีเฟรชแอปเบื้องหลัง** → เปิดให้ Garmin Connect
5. ตรวจว่าเข้าแล้ว: หลังนอนคืนแรก เปิด Garmin Connect ให้ซิงก์ → แอปสุขภาพ → เรียกดู → การนอน ต้องเห็นข้อมูลจาก Garmin Connect
   - หมายเหตุ: HRV / Body Battery / Stress **ไม่ส่งเข้า Apple Health** (ข้อจำกัดของ Garmin) · ข้อมูลเริ่มส่งตั้งแต่วันที่เชื่อม ไม่ย้อนหลัง

### ส่วน B — เตรียมลิงก์ของ Jack (คอมพิวเตอร์ · ทำครั้งเดียว)
1. Apps Script ของ Jack → วาง `Bot.gs` ใหม่ → **Deploy → Manage deployments → ✏️ → New version → Deploy**
2. เลือกฟังก์ชัน **`setupHealthLink`** → Run → ดู Execution log → **ก็อปลิงก์ทั้งบรรทัด** (…/exec?h=…) — **อย่าแชร์ลิงก์นี้** (ถ้าหลุด รัน `resetHealthLink` ได้ลิงก์ใหม่ แล้วแก้ใน Shortcut)
3. (ไม่บังคับ) Run **`testHealthPost`** → log ต้องขึ้น `"ok":true` + "[ทดสอบ ไม่ได้บันทึก] … นอน 7:15 …" (โหมดทดสอบ ไม่เขียนข้อมูลจริง)
4. ส่งลิงก์เข้าไอโฟน (เช่น ส่ง LINE หา Keep ตัวเอง / Notes) เพื่อก็อปไปวางใน Shortcut

### ส่วน C — สร้าง Shortcut "Jack สุขภาพ" (ไอโฟน · แอปคำสั่งลัด/Shortcuts)
แอป **คำสั่งลัด (Shortcuts)** → แท็บ **คำสั่งลัด** → **+** → ตั้งชื่อ **Jack สุขภาพ** แล้วเพิ่มคำสั่งตามลำดับ (พิมพ์ชื่อภาษาอังกฤษในช่องค้นหาคำสั่งได้ ชื่อไทยอาจต่างเล็กน้อยตามรุ่น iOS)
วิธีใส่ "ตัวแปร" ในช่องข้อความ: แตะช่อง → แถบเหนือคีย์บอร์ดจะมีตัวแปร (เช่น **รายการที่ทำซ้ำ / Repeat Item**) → แตะตัวแปรนั้นอีกครั้งเพื่อเลือก "คุณสมบัติ" (เช่น ค่า/Value, ระยะเวลา/Duration, วันที่เริ่ม/Start Date)

**ชุดที่ 1 — การนอน**
1. **ค้นหาตัวอย่างข้อมูลสุขภาพ (Find Health Samples)** → ประเภท **การวิเคราะห์การนอนหลับ (Sleep Analysis)** · เพิ่มตัวกรอง **วันที่เริ่ม (Start Date) · อยู่ในช่วงที่ผ่านมา (is in the last) · 1 วัน** · เรียงตามวันที่เริ่ม เก่าสุดก่อน · ไม่จำกัดจำนวน
2. **ทำซ้ำกับแต่ละรายการ (Repeat with Each)** ในผลลัพธ์ข้อ 1 → ข้างใน:
   - **ข้อความ (Text)**: `[รายการที่ทำซ้ำ → ค่า (Value)]|[รายการที่ทำซ้ำ → ระยะเวลา (Duration)]` (พิมพ์ขีดตั้ง `|` คั่นกลาง ไม่มีเว้นวรรค)
   - **เพิ่มไปยังตัวแปร (Add to Variable)** ชื่อ `sleepLines`
3. หลัง **สิ้นสุดการทำซ้ำ** → **รวมข้อความ (Combine Text)** `sleepLines` ด้วย **ขึ้นบรรทัดใหม่ (New Lines)** → **ตั้งค่าตัวแปร (Set Variable)** ชื่อ `sleepText`

**ชุดที่ 2 — ก้าวเดิน (รายวัน)**
4. **Find Health Samples** → ประเภท **ก้าว (Steps)** · Start Date อยู่ในช่วงที่ผ่านมา **2 วัน** · **จัดกลุ่มตาม (Group By): วัน (Day)**
5. **Repeat with Each** → ข้างใน:
   - **จัดรูปแบบวันที่ (Format Date)**: วันที่ = `รายการที่ทำซ้ำ → วันที่เริ่ม (Start Date)` · รูปแบบ **กำหนดเอง (Custom)** = `yyyy-MM-dd`
   - **Text**: `[วันที่ที่จัดรูปแบบ]|[รายการที่ทำซ้ำ → ค่า (Value)]`
   - **Add to Variable** `stepLines`
6. หลังจบ → **Combine Text** `stepLines` ด้วย New Lines → **Set Variable** `stepText`

**ชุดที่ 3 — ออกกำลังกาย**
7. **Find Health Samples** → ประเภท **การออกกำลังกาย (Workouts)** · Start Date อยู่ในช่วงที่ผ่านมา **2 วัน**
8. **Repeat with Each** → ข้างใน:
   - **Format Date**: `รายการที่ทำซ้ำ → วันที่เริ่ม` · Custom `yyyy-MM-dd`
   - **Text**: `[รายการที่ทำซ้ำ → ประเภท (Type/ชนิดการออกกำลังกาย)]|[รายการที่ทำซ้ำ → ระยะเวลา (Duration)]|[วันที่ที่จัดรูปแบบ]`
   - **Add to Variable** `workoutLines`
9. หลังจบ → **Combine Text** `workoutLines` ด้วย New Lines → **Set Variable** `workoutText`

**ชุดที่ 4 — ชีพจรขณะพัก (ไม่บังคับ — ถ้าไม่มีประเภทนี้ใน Health ข้ามได้)**
10. ทำเหมือนชุดที่ 2 แต่ประเภท **อัตราการเต้นหัวใจขณะพัก (Resting Heart Rate)** → ได้ `rhrText`

**ส่งให้ Jack**
11. **รับเนื้อหาของ URL (Get Contents of URL)** → URL = ลิงก์จากส่วน B · แตะ ⌄ แสดงเพิ่ม → **วิธี (Method): POST** · **เนื้อหาคำขอ (Request Body): แบบฟอร์ม (Form)** · เพิ่มช่อง (ชนิด Text ทุกช่อง):
    - `sleepSamples` = ตัวแปร `sleepText`
    - `steps` = `stepText`
    - `workouts` = `workoutText`
    - `rhr` = `rhrText` (ถ้าทำชุดที่ 4)
12. **รับค่าจากพจนานุกรม (Get Dictionary Value)** → คีย์ `message` จาก เนื้อหาของ URL
13. **แสดงการแจ้งเตือน (Show Notification)** → ข้อความ = ค่าจากข้อ 12 (จะขึ้น "Jack บันทึกแล้ว: นอน 7:20 ✓ · ก้าวเมื่อวาน 8,432 · …")
14. กด ▶ ทดลองรัน 1 ครั้ง → ไอโฟนจะถามสิทธิ์อ่าน Health ทีละประเภท → **อนุญาต (Allow) ทุกข้อ** → ต้องเห็นแจ้งเตือนของ Jack

### ส่วน D — ให้รันเองทุกวัน (ตอนเปิด LINE)
1. แอป Shortcuts → แท็บ **การทำงานอัตโนมัติ (Automation)** → **+** → **แอป (App)** → เลือก **LINE** → ติ๊ก **เปิดแล้ว (Is Opened)** → ถัดไป
2. เลือก **เรียกใช้ทันที (Run Immediately)** (ไม่ใช่ "ถามก่อนเรียกใช้") · ปิด **แจ้งเมื่อเรียกใช้** ได้ถ้าไม่อยากเห็นแบนเนอร์
3. คำสั่ง = **เรียกใช้คำสั่งลัด (Run Shortcut) → Jack สุขภาพ** → เสร็จสิ้น
- รันซ้ำหลายครั้งต่อวันได้ไม่เป็นไร (Jack เขียนทับค่าเดิม ไม่ซ้อน) · ถ้ารำคาญแจ้งเตือน ลบข้อ 12–13 ออกได้

### ตรวจว่าใช้ได้
- แอป Jack → หน้า Health → วันนี้ต้องมีเวลานอน + "จาก Garmin" · เมื่อวานมีก้าว/ออกกำลังกาย · หน้า Level ได้ XP Health (นอนถึงเป้า +10 · ออกกำลังกาย +15/ครั้ง)
- พิมพ์ `สถานะ jack` ใน LINE → บรรทัด "ข้อมูลสุขภาพจาก Shortcut: ล่าสุด …"

### ถ้ามีปัญหา
- **เวลานอนเป็น 0 / ไม่มี**: เปิด Garmin Connect ให้ซิงก์ก่อน (ข้อมูลเข้า Health หลังแอปซิงก์) · ดูแอปสุขภาพ → การนอน ว่ามีข้อมูลเมื่อคืนไหม
- **แจ้งเตือนขึ้น "ลิงก์ไม่ถูกต้อง"**: ลิงก์ใน Shortcut ไม่ตรง (หรือเพิ่งรัน resetHealthLink) → ก็อปใหม่
- **Shortcut ไม่รันเอง**: ตรวจว่า Automation เป็น "เรียกใช้ทันที" · ไอโฟนต้องปลดล็อกอยู่ (ตอนเปิด LINE ปลดล็อกอยู่แล้ว)
- **ค่าเพี้ยน**: ส่งภาพหน้าจอ Shortcut มาให้ AI ดู — ฝั่ง Jack รับได้หลายรูปแบบ (ชั่วโมง/นาที/วินาที, "7:20", "7 hr 20 min", ภาษาไทย) และทิ้งค่าที่ผิดปกติ (นอน <30 นาทีหรือ >16 ชม., ก้าว >150,000)

## ขั้นที่ 9 (ข้อ 56) — เอกสาร (Documents)

**สิ่งที่เปลี่ยน:** ส่งรูป/PDF ให้ Jack = เก็บเป็นเอกสาร (ไม่ผูกกับรายจ่ายและไม่อ่านสลิปแล้ว) · Jack เตือนเอกสารใกล้หมดอายุในสรุปเช้า · ถาม/ขอเอกสารได้ (ได้ลิงก์ Drive)

**ที่โอมต้องทำ**
1. `git push` ฝั่งแอป แล้วเปิดแอปรีเฟรช 1–2 ครั้ง (ให้ service worker v13 ขึ้น)
2. Apps Script: วาง **Bot.gs + Config.gs + Files.gs** ใหม่ทั้ง 3 ไฟล์ (ไฟล์อื่นไม่เปลี่ยน) → **Deploy → Manage deployments → ดินสอ → New version → Deploy** (ไม่ต้องรันฟังก์ชันตั้งค่าเพิ่ม)
   - ห้ามวาง `test/money-seed.gs` ใน Apps Script (เป็นของเทสต์)

**ทดสอบ**
- ส่งรูปใน LINE → Jack ถามหมวด (🪪 ประจำตัว / 👤 ประวัติ/ใบรับรอง / 🚗 ยานพาหนะ / 📁 ทั่วไป) → กดหมวด → พิมพ์ `ประกันรถ 31/12/2570` → Jack ตอบตั้งชื่อ + วันหมดอายุ → เปิดแอป หน้า Documents ต้องเห็นเอกสาร + แถบ "ใกล้หมดอายุ" (ถ้าเหลือ ≤30 วัน)
- ถาม Jack: `ประกันรถหมดเมื่อไหร่` / `ขอสำเนาบัตรประชาชน` → ตอบพร้อมลิงก์ Drive
- หมวด **งาน/ราชการ**: ในแอปสร้างเอกสาร → ต้องเห็น 🔒 ไม่มีปุ่มแนบไฟล์ · ถาม Jack ถึงเอกสารนั้น Jack ต้องไม่รู้จัก · ติ๊ก "ไม่ลับ" แล้วค่อยแนบ/ให้ Jack อ่านได้
- สรุปเช้า 07:00: เอกสารที่หมดอายุในอีก **30 วันหรือ 7 วันพอดี** ขึ้นหัวข้อ "📄 เอกสารใกล้หมดอายุ" · งาน/ราชการขึ้นแค่ "มีเอกสารงาน/ราชการ N ฉบับใกล้หมดอายุ ดูในแอป"

**ไฟล์ที่เคยแนบกับรายจ่ายไว้** ยังเปิดดูได้ในแอปเหมือนเดิม
